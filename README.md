Task 5: Wireshark Network Traffic Analysis

Objective

Capture and analyze network traffic using Wireshark to identify common network protocols.

Tool Used

* Wireshark 4.6.9
* macOS

Procedure

1. Installed Wireshark and configured packet-capture permissions.
2. Captured network traffic on the Wi-Fi interface.
3. Examined captured packets and their protocol details.
4. Saved the capture file in PCAPNG format.

Protocols Identified

* TCP: Reliable, connection-oriented communication.
* UDP: Connectionless communication.
* QUIC: Transport protocol used by modern internet applications.
* mDNS: Local network device and service discovery.

Observation

The captured traffic included TCP, UDP, QUIC, and mDNS packets. The capture screenshot showed 255 packets and zero dropped packets at that time.

Files Included

* Task5_Wireshark_Capture.pcapng — captured network traffic.
* Wireshark_Packet_Capture.png — screenshot evidence.
* Wireshark_Analysis_Report.txt — analysis report.

Conclusion

This task provided practical experience in capturing network packets and identifying network protocols using Wireshark.
